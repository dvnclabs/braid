v0.1 · for Claude Code and Codex

Every coding-agent session, saved in git as it happens.

braid keeps your agent conversations on your machine. Go back to any point of one, continue it in Claude Code or Codex, edit it before anyone sees it, and share it with your team next to the code it produced.

In Claude Code
/plugin marketplace add dvnclabs/braid
/plugin install braid@braid
/braid:init

Needs Node 22 or later and git. Without Claude Code, clone the repository and run node dist/braid.mjs init.

Go back

Before a turn that changes a lot, braid marks where the conversation stood. braid log lists the marks, and /braid:fork @2 gives you the command to continue from one in a new window.

Claude Code and Codex

A saved session continues in either agent. braid fork --to codex writes it as a Codex session, and --to claude-code goes the other way. Each agent gets the conversation the other's model read.

Edit before sharing

braid edit shows a session as it would be published, redacted, one line per record. Withhold, rewrite or hide any part of it, and put any of it back.

Share and review

git push can publish a session with the commits it produced. /braid:review 128 reviews a pull request with the sessions behind it, and /braid:merge brings the review into your conversation.

Saved correctly

braid verify checks a session the way git fsck checks a repository, and runs by itself when each session ends: every record is in the store, and a fork written from it holds what the agent reads to resume.

On autopilot, the default, nothing leaves your machine. Conversations live in ~/.braid, a git repository of their own, in ATXF, an open format for agent transcripts. No server is involved.

Terminal
$ braid verify --all
braid verify 9e36aa15: ok
  ✓ saved: 1211 records of the transcript
  ✓ loads: 53 lines since the last compaction,
    the same in a fork as in the transcript
  ✓ store: 1 chunks, git fsck
