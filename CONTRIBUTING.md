# Contributing

braid is at the design stage, so the most useful contributions are comments on the design.

- **Questions and proposals:** open an issue. Name the document and section it concerns.
- **Changes to the docs or the example:** open a pull request. Keep `examples/pr-review/conversation.atxf.jsonl` valid against the [ATXF v0.1 schema](https://github.com/leostera/atxf/tree/main/schema/v0.1).
- **Corrections to [prior art](docs/prior-art.md):** welcome at any time, with a link to the source.

Code contributions will open once milestone 1 in the [roadmap](docs/roadmap.md) has a skeleton to build on.
