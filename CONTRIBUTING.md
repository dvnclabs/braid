# Contributing

braid is at the design stage, so the most useful contributions are comments on the [design](docs/design.md).

- **Questions and proposals:** open an issue and name the section it concerns.
- **Changes to the design or the example:** open a pull request. If you change the example, edit `examples/pr-review/generate.py`, regenerate the file, and validate it as its README shows.
- **Corrections to [prior art](docs/design.md#prior-art):** welcome at any time, with a link to the source.
- **The status line prototype:** keep `prototype/statusline/test.sh` passing.
